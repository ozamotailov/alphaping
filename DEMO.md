# Демо-видео TonSonar (под грант STON.fi)

**Цель:** за 60–90с показать петлю **сигнал → свап на STON.fi** (это то, ради чего грант).
**Главный кадр («money shot»):** alert от smart-money/листинга → тап «Купить на STON.fi» →
свап подписывается в кошельке. Если в видео есть только это — уже сильно.

## Спеки
- Длина: **60–90 сек** (короче = лучше; грант-ревьюеры смотрят бегло).
- Формат: запись экрана телефона (вертикаль) ИЛИ Telegram Desktop (горизонталь 1080p). Любой ок.
- **Субтитры обязательны** (многие смотрят без звука). Закадровый голос — плюс, но не обязателен.
- Язык: **английский** (аудитория STON.fi — англоязычная). Текст ниже — EN VO/субтитры.
- Музыка: тихий фоновый трек без копирайта (опц.).

| Время | Что на экране (действие) | Субтитр / VO (EN) |

## Как записать (просто)
1. **Подготовь данные заранее:** подключи кошелёк с парой TON; добавь в отслеживание активный
   smart-money кошелёк (или дёрни `/testlisting`, чтобы прилетел алерт с кнопкой свопа для записи).
2. **Запись экрана:**
   - Телефон: встроенная запись экрана (iOS: Control Center; Android: Screen Record).
   - Или Telegram Desktop + OBS Studio (бесплатно), окно бота.
3. **Сделай реальный мелкий своп** (0.5–1 TON) ради «живого» кадра подписи — это самый убедительный момент.
4. **Смонтируй** в CapCut / DaVinci Resolve (бесплатные): обрежь паузы, добавь субтитры из таблицы,
   крупно покажи кнопку «Купить на STON.fi» и экран котировки.
5. **Длина 60–90с.** Безжалостно режь ожидания (загрузки ускорь 2–4×).
